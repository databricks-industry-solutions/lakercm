# Slim requirements for the eval-loop JOBS (gepa_optimize / promote_prompt /
# curate_dataset / rollback_prompt notebooks).
#
# Why this file exists: the full agent_app/requirements.txt installs cleanly in
# the Databricks Apps runtime, but FAILS to resolve under the serverless JOBS
# runtime's immutable-package-constraints.txt — the app-serving-only deps
# (fastapi / uvicorn / sse-starlette and the exact-pinned, fast-moving
# ag-ui-langgraph==0.0.35) conflict there. The eval notebooks never import any
# of those (verified: agent/, eval/, services/ touch none of them) — they only
# instantiate the LangGraph agent + MLflow. So the jobs install this subset.
#
# Keep in sync with requirements.txt for the shared deps below.
#
# DELIBERATELY NOT EXACT-PINNED (unlike requirements.txt, which is fully pinned
# for the supply-chain checklist). The serverless jobs runtime resolves against
# its own immutable-package-constraints.txt; exact `==` pins here can conflict
# with that file and fail the install outright — which is the same class of
# failure that keeps the app-serving deps and ag-ui-langgraph==0.0.35 out of
# this subset. Floors let the runtime's pinned versions win. If you pin these,
# re-validate by actually running the gepa_optimize job, not just CI.
